# Protogen visor wiring package (rev 2026-11-09)

From: the deck session "esp32-av-ndi-streaming protogen kickoff (2)" (cybrdek, a ClockworkPi uConsole). For: the t14-runner session.
Owner of the hardware: Gil. This is a wiring diagram + netlist for a protogen visor: two ESP32-S3 N16R8 boards (visor controller S3V and
wrist module S3W) joined by ESP-NOW, driving two HUB75 LED panels, sensors, a mic pair, a DAC, a servo driver, a fan, and a 12 V -> 5 V power chain.

## What is in here
- `hardware.yaml`  SINGLE SOURCE OF TRUTH: parts (with real pin names), nets (every node `PART.PIN`), status (built / planned / temporary / optional).
- `out/visor_wiring.pdf` and `out/visor_wiring_0N_*.svg`  5 pages: 1 overview, 2 visor matrix + I/O, 3 visor I2C + audio, 4 wrist module, 5 GPIO and power tables.
  Rendered on the deck with matplotlib (the deck has no WireViz, SkiDL or KiCad). Dashed = planned / temporary / optional, solid = built and tested.
- `out/netlist.json`, `out/netlist.csv`  the netlist (62 nets, 216 nodes, 42 parts). CSV has one row per node.
- `out/visor.wireviz.yaml`, `out/wrist.wireviz.yaml`  WireViz sources, GENERATED by `gen_formats.py`. **NOT RUN anywhere yet.**
- `out/build_skidl.py`  SkiDL script that builds the netlist from `netlist.json` with generic parts. **NOT RUN anywhere yet.**
- `out/validation.txt`  my own checks: no pin in two nets, no reserved GPIO used, I2C addresses unique per bus, and 29 cross-checks of the netlist against the
  hand-written pin tables in `sources/` (all pass).
- `hwlib.py`, `gen_formats.py`, `render_diagrams.py`, `build_all.py`  the generators (Python 3, PyYAML, matplotlib). `python3 build_all.py` regenerates `out/`.
- `sources/`  the written pin tables and the design prompt this was built from.

## Known limits
- Netlist = connectivity only. No footprints, no KiCad symbols, no electrical values beyond the notes (fuse ratings are in the part notes and page 5).
- Panel 1 OUT -> panel 2 IN is a straight 16-pin ribbon that is described but not netlisted per pin. HUB75 pin 8 (E) is intentionally open.
- The DAC (PCM5102A type) is not bought yet; its pins are generic, check the module's solder jumpers when it arrives.
- GPIO19/20 (USB) and GPIO0/45/46 (strapping) are reserved; GPIO18 is not broken out on the wrist board's base.
